# 操作系统课程设计

本项目为《操作系统》课程设计实现，采用 `C + Linux 命令行 + pthread`，包含以下内容：

- 处理机调度：`FCFS / SJF / RR / Priority`
- 内存管理：`FF / BF / FIFO / LRU`
- 进程同步：`生产者-消费者 / 读者-写者`
- 文件系统：`创建 / 写入 / 读取 / 删除 / 列目录`
- 扩展模块：`调度算法性能对比`

## 目录结构

```text
.
├── include/              # 头文件
├── src/                  # 源代码
├── data/                 # 示例输入数据
├── examples/             # 示例输出说明
├── Makefile              # Linux 构建脚本
└── README.md
```

## 编译与运行

```bash
make
./os_course_design
```

若需清理构建文件：

```bash
make clean
```

## 模块说明

### 1. 处理机调度

- 支持动态输入进程名、到达时间、服务时间、优先级、时间片
- 支持一次性运行所有算法
- 输出执行顺序、开始时间、完成时间、周转时间、带权周转时间、平均指标

### 2. 内存管理

- 动态分区分配：`FF`、`BF`
- 页面置换：`FIFO`、`LRU`
- 输出分配回收过程、页框状态、缺页次数、缺页率

### 3. 进程同步与并发控制

- 使用 `pthread_mutex_t` 和 `sem_t`
- 通过线程日志展示同步过程
- 支持 `生产者-消费者` 与 `读者-写者`

### 4. 文件系统

- 模拟简化目录结构与空闲空间管理
- 支持文件创建、写入、读取、删除、目录查看

### 5. 扩展模块

- 对多种调度算法给出示例性能对比
- 可直接用于实验分析与报告结论部分
